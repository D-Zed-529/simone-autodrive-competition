# 比赛背景

本项目源自 **2025 届中国大学生工程实践与创新能力大赛** 的
**虚拟仿真赛道 - 智能网联汽车设计赛项**。

代码面向 SimOne 仿真场景，采用规则驱动的感知、决策、路径规划和车辆控制逻辑，
用于完成循迹、避障、路口通行、交通灯响应和限速遵守等比赛任务。

## 项目范围

- 面向 SimOne 场景的比赛型自动驾驶逻辑。
- 使用 C++ 实现，调用 SimOne HD Map、Sensor、Service 和 PNC API。
- 采用规则驱动方案，不是通用量产级自动驾驶系统。

## 说明

- 部分场景特化分支被保留下来，因为它们属于原始比赛方案的一部分。
- 项目主要用于学习、复盘和在匹配的 SimOne 环境中复现。
- 推荐运行环境是 Windows + Visual Studio/MSVC + SimOne runtime。
- macOS/Linux 可以做 CMake 配置和源码级语法检查，但不能替代 Windows 构建与
  SimOne 运行测试。

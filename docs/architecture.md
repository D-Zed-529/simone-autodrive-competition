# 系统架构概览

AutoDrive 是一个单进程 SimOne 客户端程序。主循环位于
`Impl/app/autodrive.cpp`，负责读取仿真状态、更新驾驶决策、生成或复用路径、
计算控制量，并调用 SimOne 帧同步接口推进仿真。

## 运行循环

1. 初始化 SimOne API、评估服务、HD Map、起终点和 PID 速度控制器。
2. 每一帧读取 GPS、障碍物真值、车道连接关系、停止线、交通灯和交通标志。
3. 更新驾驶状态，包括正常循迹、路口处理、换道、避障和紧急制动。
4. 在需要时生成换道或避障局部路径，否则继续复用全局路径。
5. 计算方向盘、油门和刹车控制量，设置信号灯，并调用
   `SimOneAPI::NextFrame` 进入下一帧。

## 源码布局

- `Impl/app/`：程序入口和驾驶状态机。
- `Impl/common/`：项目内部共享类型和函数声明。
- `Impl/perception/`：障碍物、交通标志和路口感知辅助逻辑。
- `Impl/decision/`：换道、安全区域和路口决策辅助逻辑。
- `Impl/planning/`：路径采样、路径截取和换道路径生成。
- `Impl/control/`：PID 速度控制器。
- `Impl/util/`：数学、字符串和车辆控制工具函数。

## 设计边界

代码保留 SimOne SDK 的类型、字段和 API 命名。项目自有辅助函数尽量使用更清晰的
命名，但比赛时期的部分场景特化分支仍然显式保留，方便追溯原始比赛策略。
